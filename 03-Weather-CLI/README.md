# 🌤️ CLI Weather Tracker

A lightweight, interactive Command Line Interface (CLI) application built with Python. It fetches real-time weather metrics using the OpenWeatherMap REST API and displays formatted output directly in your terminal.

---

## 🌟 Key Features

* **Real-Time Weather Data:** Displays temperature, "feels like" temperature, atmospheric humidity, and weather conditions.
* **Rich Terminal Formatting:** Uses the `rich` library to present data in styled tables and panels.
* **Environment Security:** Protects sensitive API credentials using `python-dotenv` and `.env` configuration.
* **Error Handling:** Robust handling for HTTP errors, invalid city queries, and missing credentials.

---

## 🛠️ Tech Stack & Libraries

* **Python 3.x**
* **Requests:** For sending HTTP requests to the OpenWeatherMap REST API.
* **python-dotenv:** For loading environment variables from a `.env` file.
* **Rich:** For enhanced terminal formatting and visual UI elements.
