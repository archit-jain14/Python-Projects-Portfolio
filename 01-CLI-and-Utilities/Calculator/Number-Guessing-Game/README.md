# 🎯 Number Guessing Game

A fun and interactive Command-Line Interface (CLI) game built using Python. The computer selects a random number between 1 and 100, and the player tries to guess it with helpful hints provided after each attempt.

---

## ✨ Features
* 🎲 **Random Number Generation:** Uses Python's built-in `random` module.
* 💡 **Smart Hints:** Tells you if your guess is **Too High** or **Too Low**.
* 🏆 **Attempt Counter:** Tracks how many tries it took you to win.
* ⚠️ **Input Validation:** Handles invalid inputs (like letters or out-of-bound numbers) gracefully without crashing.
