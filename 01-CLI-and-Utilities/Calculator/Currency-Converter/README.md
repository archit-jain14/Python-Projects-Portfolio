# 💱 Real-Time Currency Converter

A Command-Line Interface (CLI) application built using Python that fetches live exchange rates via an external API to convert currencies in real-time.

---

## ✨ Features
* 🌐 **Live Rates:** Fetches real-time exchange rates using a Currency API.
* 💵 **Multi-Currency Support:** Convert between popular world currencies (USD, INR, EUR, GBP, etc.).
* 🛡️ **Network Error Handling:** Gracefully handles offline mode or API failure using `try-except`.
* 🔢 **Input Validation:** Prevents invalid numerical inputs and unknown currency codes.
