# 🌤️ CLI Weather Tracker

A Command-Line Interface (CLI) application built in Python that fetches real-time weather details (temperature, humidity, weather conditions, wind speed) for any city using external web services.

---

## ✨ Features
* 🌡️ **Live Temperature:** Displays real-time temperature and "feels like" metrics in Celsius.
* 🌧️ **Weather Conditions:** Fetches current atmospheric conditions and humidity percentage.
* 💨 **Wind Speed:** Displays real-time wind speed in km/h.
* 🛡️ **Robust Error Handling:** Handles invalid city inputs and connection timeouts gracefully.
