# 💸 CLI Expense Tracker

A Command-Line Interface (CLI) application built using Python to track daily expenses, analyze category-wise spending, and persist data locally using JSON.

---

## ✨ Features
* ➕ **Add Expenses:** Log title, amount, category, and automatic timestamp (`YYYY-MM-DD HH:MM:SS`).
* 📊 **Category Summary:** View total spending breakdown grouped by categories (Food, Travel, Bills, etc.).
* 📋 **View History:** Tabular display of all transactions with total expense calculation.
* 💾 **Data Persistence:** Automatically saves and loads transactions from `expenses.json`.
