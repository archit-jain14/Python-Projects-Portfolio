# 📝 To-Do List CLI App

A persistent Command-Line Interface (CLI) task manager built using Python. Tasks are automatically saved to a local JSON file (`tasks.json`), ensuring your data persists even after closing the program.

---

## ✨ Features
* ➕ **Add Tasks:** Quickly add new tasks to your list.
* 📋 **View Tasks:** Display all tasks along with their current status (✅ Done / ❌ Pending).
* ✔️ **Mark Completed:** Update task status dynamically.
* 🗑️ **Delete Tasks:** Remove unwanted tasks from the list.
* 💾 **Data Persistence:** Automatically reads and writes tasks using Python's `json` module.
