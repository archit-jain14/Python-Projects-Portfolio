# 🔐 Random Password Generator

A customizable Command-Line Interface (CLI) tool built using Python to generate strong, secure, and random passwords.

---

## ✨ Features
* 📏 **Custom Length:** Specify any password length (minimum 6 characters).
* 🔣 **Character Selection:** Choose whether to include numbers and special characters.
* 🛡️ **Guaranteed Complexity:** Ensures at least one lowercase, uppercase, number, and symbol (if selected) are included.
* 🔀 **Randomized:** Uses Python's `string` and `random` modules for maximum security.
