# 🕸️ Web Scraper & Data Extractor

A Python automation tool that scrapes top trending tech news headlines from Hacker News using `requests` and `BeautifulSoup4`, and exports the extracted data into both JSON and CSV formats.

---

## ✨ Features
* 🌐 **Automated Scraping:** Extracts headlines and target article URLs seamlessly.
* 📄 **Multi-Format Export:** Saves structured data into both `news.json` and `news.csv`.
* 🛡️ **User-Agent Handling:** Bypasses basic scraper blocking using standard browser headers.
